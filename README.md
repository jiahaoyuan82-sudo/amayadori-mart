# ☂ あまやどりマート · 雨夜便利店

一个日式雨夜便利店经营小游戏，用等距（isometric）低多边形风格做成的网页游戏。
纯 HTML + CSS + 原生 JavaScript，**零依赖、无需构建**，直接打开 `index.html` 就能玩，放到 GitHub Pages 即可上线。

## 玩法

底部工具栏：**⏸ 暂停 · ▶ 加速（1/2/4 倍）· 📦 进货 · 👥 人员 · 📊 财报 · 🌤 天气 · ☰ 菜单**

货币为 **人民币（元）**。

- **📦 进货**：9 大类、31 种商品，按箱订货，送货车约 40～80 分钟后送到**仓库**；进价每天浮动，售价可自己调（每次 ±0.5 元，定太贵客人会不买）。「杂志 / 日用品 / 热食 / 冰品」需要花钱解锁。
- **🥫 自动贩卖机**：店门口三台（饮料 / 咖啡 / 矿泉水）是你的。路人会顺手买一罐，天冷咖啡好卖、天热矿泉水好卖。在「进货 → 贩卖机」里补货和调价，也可以直接点贩卖机。
- **⬆ 上架**：点店里的货架，把仓库的货摆上去。
- **💴 结账**：点收银台前头上有 💴 的客人。雇了收银员会自动结账。
- **👥 人员**：每天有一批随机应聘者，长相、性格、能力、时薪都不同，有完整的「履歴書」简历。安排早 / 晚 / 夜班和岗位（收银 / 补货 / 自动）。补货员还会打扫地面。
  - **时薪最低 ¥20**，按能力最高 ¥36；**夜班（22:00–6:00）×1.5**；**周末每小时 +¥2**。工资每小时结算。
- **📊 财报**：今日收支（含贩卖机收入）、近两周图表、预测 vs 实际客流、商品排行、错失的生意（缺货 / 嫌贵 / 店里太挤）。
- **🌤 天气**：未来 15 天天气、气温、降水概率、预测客流（不一定准），以及祭典、施工等特殊日子。
- **🎲 随机事件**：小偷（点他抓住）、门口的流浪猫（点它摸摸）、旅游团、放学的学生、网红探店（好评后两天客流 +20%）、醉汉、常客（田中爷爷、加班的佐藤小姐、外卖小哥、小健）、掉在地上的钱包、打翻的饮料、员工发烧请假、供应商促销、赠品、设备故障、客流高峰……
- **💬 对话**：客人和店员会不时说话，用漫画风对话框（普通 / 大喊 / 心里想）。
- **🍙 イートイン**：买了热食或便当的客人有时会坐在窗边吃完再走。
- **🎨 画风**：菜单里可以切换「普通 / 漫画风」（黑白网点纸风格，界面也会变成漫画风）。

**操作**：电脑 = 拖动平移、滚轮缩放、`空格` 暂停、`1~4` 打开四个面板、`R` 屋顶、`Ctrl+S` 保存、`Esc` 菜单；手机 = 单指拖动、双指缩放

## 存档

- **自动保存**：每 10 秒、切到后台/锁屏、关闭网页时自动保存（存在本机浏览器 localStorage）
- **手动保存**：工具栏 💾
- **继续游戏**：标题画面「继续上次」会显示存档的天数和金钱
- **防误删**：有存档时点「开店营业」会先弹窗确认，不会直接覆盖
- **换设备**：菜单 →「导出存档码」复制一串 `AMA3-...` 文字 → 在新设备的标题画面或菜单里「导入存档码」粘贴
- 注意：清除浏览器数据或使用无痕模式会丢失本机存档，重要进度请导出存档码
- 这一版存档格式升级（v3），旧版本的存档不能读取

## 手机

- 竖屏、横屏都适配；竖屏会自动放大店内画面，按钮和点击范围加大
- 适配 iPhone 刘海/底部横条（安全区）
- 可以「添加到主屏幕」，像 App 一样全屏打开（iPhone：Safari 分享 → 添加到主屏幕；安卓：Chrome 菜单 → 添加到主屏幕）

## 文件结构

```
├── index.html        页面结构（标题画面 / HUD / 工具栏 / 弹窗）
├── manifest.json     添加到主屏幕用的应用信息
├── icons/            应用图标
├── css/style.css     界面样式
└── js/
    ├── iso.js        等距渲染工具：坐标投影、方块、平面贴字、光晕、深度排序
    ├── data.js       ★ 游戏数据：商品价格、货架位置、客流时段、人物配色（改数值改这里）
    ├── world.js      场景：地面、便利店建筑、货架、街道道具、夜间灯光
    ├── people.js     人物外观：顾客/路人/店员、雨伞
    ├── audio.js      用 WebAudio 合成的音效（入店铃、收银、雨声），不需要音频文件
    ├── sim.js        经营模拟：库存进货送货、财务、天气预报与客流、员工生成/AI、简历头像
    ├── main.js       画面与顾客：自然走路（转向/加减速/避让）、顾客选品与路线、イートイン、输入、气泡
    ├── events.js     随机事件 & 漫画风对话
    ├── ui.js         界面：HUD、工具栏、菜单、存档（自动/手动/存档码）、新手引导、启动
    └── panels.js     四个面板：进货、人员（含简历）、财报、天气
```

## 上传到 GitHub 并开启网页

```bash
git init
git add .
git commit -m "first version"
git branch -M main
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main
```

然后在仓库页面：**Settings → Pages → Build and deployment → Source 选 “Deploy from a branch”，Branch 选 `main` / `(root)`** → 保存。
一两分钟后访问 `https://<你的用户名>.github.io/<仓库名>/` 就能玩。

## 常见修改

| 想改什么 | 去哪里 |
|---|---|
| 商品（名字/进价/售价/每箱数量/人气/天气敏感度） | `js/data.js` → `PRODUCTS` |
| 商品类别、解锁价格 | `js/data.js` → `CATEGORIES` |
| 员工性格、名字、学校、工作经历、简历文案 | `js/data.js` → `TRAITS` / `SURNAMES` / `SCHOOLS` / `PAST_JOBS` / `MOTIVES` … |
| 时薪下限/上限、夜班倍率、周末补贴 | `js/data.js` → `WAGE_MIN` / `WAGE_MAX` / `NIGHT_RATE` / `WEEKEND_BONUS` |
| 随机事件（种类、概率） | `js/events.js` → `EVENT_DEFS` |
| 对话台词 | `js/events.js` → `LINES` / `REGULARS` |
| 自动贩卖机 | `js/data.js` → `VEND_DEFS` |
| 每日基础客流 | `js/sim.js` → `expectedTraffic()` 里的 `165` |
| 天气种类、特殊活动 | `js/data.js` → `WEATHER` / `EVENTS` |
| 初始资金、店名 | `js/data.js` 顶部 |
| 时间流速 | `js/main.js` → `MIN_PER_SEC` |
